## Install

### On Linux / Android(Termux) / Mac

```bash
curl -fsSL https://raw.githubusercontent.com/Orbinuity/AiMan/main/install.sh | sh
```

### On Windows

```powershell
irm https://raw.githubusercontent.com/Orbinuity/AiMan/main/install.ps1 | iex
```
